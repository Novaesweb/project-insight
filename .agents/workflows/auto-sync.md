---
description: Sincronização automática do repositório
---
O usuário costuma fazer atualizações e commits usando outro aplicativo. 

Como regra absoluta, **ANTES** de iniciar qualquer alteração, planejamento, ou execução de código, você deve **OBRIGATORIAMENTE** sincronizar o repositório local com o remoto usando o seguinte comando:

```bash
// turbo
1. git pull
```

Após executar o `git pull` com sucesso, analise se houve alguma atualização que impacte o contexto atual e, se necessário, adapte o seu planejamento. Só depois disso, inicie o seu trabalho e faça as modificações solicitadas.
